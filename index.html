StreamHUD Studio

Windows and Linux
In active development

A node-based environment for creating, designing, animating, and deploying custom streaming overlays: from a webcam border to interactive HUDs, animated alerts, and chat displays.

  • Position Stage: drag, resize, rotate, group, and snap elements on a live view of the compiled overlay.
  • Visual assets: shapes, SVG, images, transparent video, gradients, text, and custom fonts.
  • Animation and behavior: presets, keyframes, counters, countdowns, alert queues, and chat displays.
  • Platforms: Twitch first, with YouTube, Kick, and TikTok planned.
  • Custom code, testing, and lessons: your own HTML, CSS, and JavaScript, an event simulator, a console, and guided onboarding.

Projects compile to ordinary HTML, CSS, JavaScript, and assets for OBS or any browser source. Once compiled, your overlay does not need Studio running.

Windows version: $20 packaging fee.

Pairs with StreamGuard. StreamHUD builds how your stream looks. StreamGuard keeps it healthy.

Bot Forge Studio

Linux AppImage · Windows and Mac editions
Python 3 · discord.py · GPL-3.0

A desktop node-driven IDE, compiler, and lifecycle manager for Discord bots. Design behavior with nodes, then generate real, readable, editable code that belongs to you.

  • Generated Python projects: bot.py, cogs/, runtime modules, requirements, and manifests.
  • Optional dashboard: Node.js, Express, and WebSockets for a web-facing interface.
  • Extensible: custom nodes and plugins, including .bsmod packages.
  • Deployment: local and SSH-based remote deployment, service management, project sync, and hot reload.

The node library grew out of roughly seven to eight real Discord bots. Generated projects run without Bot Forge Studio installed.

Windows: a packaged Windows build is available on Ko-fi for a $20 packaging fee.

Mac: the Mac edition is $20 on Ko-fi. On Mac, Bot Forge Studio sets up the files to self-host on a Linux server. The Linux AppImage and the source remain GPL-3.0.

Conky Studio

Linux · PyQt6 · AppImage
No sudo needed for normal use

An advanced visual node-based IDE and theme manager for Conky. Build themes without hand-editing configuration files and restarting to check coordinates.

  • Position Stage: arrange theme elements on a live visual workspace.
  • 98 built-in nodes, plus custom nodes, API integrations, and community plugins.
  • Visual effects: advanced image effects and holographic-style image changes.
  • Runtime Manager: manage existing Conky themes without rebuilding them in the editor.
  • Community: an extensive wiki and OpenDesktop and Pling integrations.

ContainerQT Studio

Linux · Python · PyQt6 · AppImage
Needs Docker
Joining the Studio lineup soon

A desktop app for developing inside Docker. Pick a Linux distribution, click once, and get a ready-to-use environment: a build window for packaging, a desktop you can look at like a VM, drag-and-drop file import, and one-click export of results back to your computer.

  • Test on the Linux you ship for: Ubuntu, Debian, Fedora, Rocky and Alma, Arch, openSUSE, Alpine, Kali, or any Docker image.
  • Build in a matching environment: an AppImage on an old glibc, a .deb on Debian, an RPM on Rocky.
  • Try many desktops: KDE Plasma 5 and 6, GNOME, XFCE, Cinnamon, MATE, i3, Sway and more, embedded in the window through noVNC.
  • Repeat yourself less: save setups as templates, builds as profiles, and environments as clones.
  • Keep your system drive free: park persistent environments on another Linux drive, or use throw-away one-time environments.
  • Fix, health checks, and a resource advisor that repairs Docker and your environments and suggests CPU and memory, while you decide.

Containers are not virtual machines. They share your computer's kernel and are less isolated than a VM, so use ContainerQT Studio with software and files you trust.

StreamGuard

Closed beta

A chat bot and dashboard for Kick and Twitch that keeps your stream healthy.

StreamGuard is currently in a closed beta. Access is limited while it is tested. To ask about joining, reach out on the CUXL Discord.

It keeps your chat clean, stops scam bots, answers commands, runs timers and redeems, and shows how every stream went, all from one place. StreamGuard is a paid supporting service for StreamHUD Studio: StreamHUD handles creating your HUD, and StreamGuard looks after the stream itself. It is Kick first, because Twitch already has established bots and tools. Run one channel or both, and share settings, statistics and a single combined chat.

Cleaner chat

  • Word, phrase and pattern rules that still catch look-alike letters, odd spacing and hidden characters.
  • Five severity levels with repeat-offender escalation (warning, timeout, ban), all changeable.
  • Fake Discord invites, scam links, spam and shouting handled automatically. Links are never opened.
  • Try any message first and see what StreamGuard would do, with nothing sent.

Scam bot and hate raid protection

  • Recognises "add me on Discord" and "buy followers" bots, even when disguised.
  • A quiet bot watchlist, plus your own patterns for bots that repeat the same few messages.
  • Kick hate raid mode, with your own terms and thresholds.

Commands, timers and fun

  • Your own commands with variables (names, counters, random numbers, time), plus ready-made ones like !hug, !roll, !joke and !uptime.
  • Timers that post messages and can show pictures, GIFs and sounds on stream.
  • The Naughty or Innocent chat game, counters and quotes.

Kick redeems

  • Rewards can press VTube Studio hotkeys, play sounds, read text aloud, change OBS scenes and more.

Stats and combined chat

  • Compare each stream with your last: viewers, chatters, bans, new followers and subs.
  • Kick and Twitch chat in one list with quick actions, in a pop-out window, a floating dock or an OBS dock.
  • Choose whether what you type goes to Kick, Twitch or both, and swap on the fly.

Teams

Add moderators and choose exactly what each may do, from editing rules and quick-action buttons to adding scam bot patterns, switching on raid mode and reading the audit log. You can also limit a moderator to the moderator panel only. A full audit log records who did what. Your data is yours: disconnect or delete everything at any time.

Getting started in about 2 minutes

Streamers: log in with Kick or Twitch, press Connect channel and approve every permission, then open Channels & access and press Send test message. Skipped permissions switch off the features that need them. Kick only sends chat to the bot while you are live, so test while streaming.

Moderators: log in as a moderator, request access to the streamer's channel under Channels & access, and once they approve it appears in your drop-down. You can only do what the streamer allowed.

Price

Planned pricing: on servers with subscriptions switched on, StreamGuard is $9.99 a month per streamer account. One subscription covers all your channels and all your moderators, and moderators never pay. Manage billing in the dashboard. Payment happens on Stripe's own page, so your card number never touches StreamGuard.

Kalium

Linux modding environment manager for Steam, Proton, and Mod Organizer 2.

Kalium is a CUXL product. It prepares, configures, and maintains Windows Mod Organizer 2 environments through Steam and Proton: the compatibility layer, Steam integration, Wine prefixes, instance configuration, Nexus downloads, supporting tools, and diagnostics. It does not replace MO2.

Kalium prepares the environment. MO2 manages the mods.

Environment management

  • Steam shortcut creation and registration, with Proton and Wine configuration.
  • Per-instance prefixes, with multiple independent MO2 instances, even for the same game.
  • Native, Flatpak, and Snap Steam, plus Heroic and GOG and Epic game environments.
  • Steam libraries on secondary drives.
  • Nexus (NXM) links routed to the intended instance.
  • Proton 10 and newer; GE-Proton Latest suggested.
  • MO2 installation, migration, and repair that preserves instance identity.

Tools and compatibility

  • Pandora Behaviour Engine, Nemesis, xEdit and SSEEdit, BodySlide and Outfit Studio, and Windows LOOT.
  • USVFS 0.5.7.2 support, optional and off by default because of reported freezes and lock-screen issues in some setups.
  • SKSE setups need the MO2 launch environment; plain asset mods can work with direct Steam launches.
  • Skyrim SE and AE backpatching is tested, including ContentCatalog.txt.bak. Fallout 4, Starfield, Cyberpunk 2077, and The Witcher 3 backpatching is experimental.
  • A command-line interface for supported maintenance tasks.

Tested against a Skyrim setup of 500 real mods, not counting Pandora and LOOT, which are tools.

Distribution: AppImage, with TAR and ZIP archives as fallbacks for GLIBC compatibility problems. Built with Python 3.10+ and PyQt6 for Linux. GPL-3.0 license.

Roadmap: more integrated tools in the application hotbar, expanded Pandora integration, xEdit, Outfit Studio and BodySlide integration, and Wabbajack support.
